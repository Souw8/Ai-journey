# CLI-ассистент с инструментами

Простой ассистен для вычислений и запоминание 

## Что умеет
- можно делать основные вычисление
- сделанные действие можно сохранить для дальнейших действий
- можно сохраненные результаты вытащить

## Как работает
Сперва включаете программу в терминале и подключаете свою виртуалку и дальше задаете вопросы и полученный ответ  он преоброзует нужные инструменты и сслыается на функции  и так вывот ответ
